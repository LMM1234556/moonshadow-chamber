# 规则机器人公平性基线（阶段 8.1）

## 评测设计

- 基准种子：`20261021`
- 主基线：旧策略与修复后策略各 1000 局，共用完全相同的身份、座位和引擎随机种子。
- 场景覆盖：6 个真人座位 × 3 种真人身份；无人值守时由对应版本的规则机器人代理真人行动。
- 教学配置补充：真人固定 P1、身份固定预言家，新旧策略各 1000 局。
- 首次夜袭目标率：某席位在首个实际发生狼人行动的夜晚仍存活且为非狼人时，被至少一名狼人选择的比例。当前首夜保护规则下，该夜晚通常是第 2 夜。
- 首日票数占比与首日被投出率分别统计，不与夜袭指标合并。
- 比例区间采用 Wilson 95% 置信区间；平均轮次使用正态近似 95% 区间。

## 结论与限制

- 已消除旧策略直接选择第一个候选所造成的确定性座位偏置。
- 修复没有引入非法行动、异常结束或流程不完整。
- 当前阵营胜率仍明显偏向狼人。修复前后总体胜率接近，说明座位公平性和阵营策略强度是两个不同问题。
- 票数占比是描述性指标；同一局内投票存在相关性，不应把单票当作完全独立样本解释置信区间。
- 真人席位由机器人代理，因此结果不是人类玩家胜率，也不能替代真人可用性测试。
