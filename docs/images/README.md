# 作品集截图来源

本目录图片均由项目自己的 Playwright/Edge Chromium 浏览器验收流程截取，画面来自本仓库的真实运行页面，没有使用外部产品截图或静态伪造界面。

| 文件 | 对应状态 | 来源 |
| --- | --- | --- |
| `game-main-desktop.png` | 桌面端白天发言主界面 | `artifacts/game-day-desktop.png` |
| `night-check-desktop.png` | 桌面端夜晚查验与目标确认 | `artifacts/game-initial-desktop.png` |
| `day-speech-mobile.png` | 移动端白天发言 | `artifacts/game-day-mobile.png` |
| `game-result-desktop.png` | 桌面端胜负结算与身份揭晓 | `artifacts/game-result-desktop.png` |
| `game-mobile.png` | 移动端夜晚初始状态 | `artifacts/game-initial-mobile.png` |

`artifacts/` 是可重复生成的测试产物目录，已被 Git 忽略；`docs/images/` 保存经过筛选、用于 README 和案例文档的公开截图。
