## 来源记录

本目录中的两张位图均在「月影议事厅」视觉升级阶段通过 AI 图像生成工具为本项目定制生成，并由项目代码本地引用；它们不是从第三方网站、游戏或影视作品中下载的素材。提交到仓库的是生成结果，不包含外部人物、品牌标识或已知作品角色。

## 当前资源

- `backgrounds/moonlit-castle-hall.jpg`：原创月光古堡大厅背景，宽屏构图；CSS 会叠加暗色遮罩，资源缺失时自动回退到纯 CSS 夜色背景。
- `portraits/neutral-cast-atlas.jpg`：原创 3 × 2 中立人物肖像图集。六名玩家只按席位取不同画面，不表达狼人、预言家或村民身份。

## 替换正式资源

头像配置位于 `web/app.js` 的 `portraitProfiles`。当前配置通过 `src`、`size` 和 `position` 从图集中取图；以后可把任意玩家替换成独立文件：

```js
{ src: "/assets/portraits/player-01.webp", size: "cover", position: "center 28%" }
```

建议头像源文件为 **512 × 640 px** 或相同比例的 WebP/AVIF，主体保持头肩构图并预留椭圆裁切安全区。所有席位应使用一致的镜头距离、光向和背景；不要加入阵营色、职业徽记、兽化特征或其他身份暗示。

建议舞台背景源文件为 **1920 × 1080 px** 以上、16:9 横图，中心区域保持低细节，避免与议事桌、阶段文字和玩家席位争夺注意力。
